# Baseline pilot review — historical v1 evaluation

Fixes committed as `f01ac30` (Validate reused translations and correct experiment scoring and selection).

This report preserves the original pilot scores from before InkGallery v2. It has not been rescored; the new evaluation uses a different denominator. See [EVALUATION.md](EVALUATION.md).

## Run

- Model: `qwen3.5:9b`, Q4_K_M, thinking off, context 8192.
- All five prompt variants; full dialogue; model-default temperature and 0.2; three repeats each.
- 30 configurations/repeats; 53 actual requests of 54 planned. One female pass was skipped after male validation failed.
- Model reported 100% GPU placement. Total request wall time: 348.49 seconds (includes the first load).
- 12 English lines supplied as context; the same eight target lines scored in every configuration.
- Two actual requests failed structural validation: reframed/default repeat 2 changed `<CHARNAME>` to `%name%`; markup/default repeat 3 omitted braces around a variant.

Command (from repository root):

```bash
python3 -u tra_files_llm_translating/experiments/diagnose_translation.py --models qwen3.5:9b --prompts production,reframed,reframed-addressee,examples,markup --scopes full --think off --temperatures default,0.2 --repeats 3 --num-ctx 8192 --out tra_files_llm_translating/experiments/results/pilot-f01ac30
```

## Manual reading

Read all 12 lines in both passes for every production/default and examples/0.2 repeat, representative markup outputs, and the reframed/default repeat that passed every check.

- **The production/default winner still needs editing.** Repeat 1 @48 leaves `downstairs` in English; @16 renames Ink Gallery to `Талая Галерея`. The female pass rewrites unrelated wording in @16 and changes plural Cowled Wizards to singular `Чародеем в Мантии` in @20. Repeat 3 @100 retains masculine `видел` in the female version. Other lines show awkward Russian and unstable terminology.
- **Worked examples improve one observed gender case but do not solve meaning.** Examples/0.2 gets Velcealle's feminine address in @18 right across all three repeats and both passes. However, every repeat translates “how I'm doing” as `как я делаю`, and two repeats leave `downstairs` untranslated in both passes. Cowled Wizards becomes `заклинателями в масках` throughout those repeats.
- **A perfect regex score can conceal serious errors.** Reframed/default repeat 1 passes 46/46 checks, yet turns “downstairs” into `на кухне` and Ink Gallery into `Галерея Травы`. Its @20 also has bad agreement (`с чародеев в плащах`), with an unrelated correction in the female pass.
- **Markup is not reliable on this model with these settings.** Representative successful requests emit ordinary masculine text without gender markup, so the derived female version remains identical and wrong. Another request emits malformed markup and fails validation. It is faster per completed pair, but loses substantial gender correctness.
- **Hand-labelled addressees give a small score gain, not a complete fix.** This oracle variant reaches 129/138 at default temperature, only two checks above production/default, and still has a masculine-address failure. It requires input production does not have.
- **The checks need careful interpretation.** Requiring a gallery stem misses incorrect names. The @48 idiom regex also rejects alternative wording such as `как я справляюсь`; those failures are not all equivalent to the definite error `как я делаю`. Some scored negatives may therefore reflect narrow expected wording.

## Decision

The automatic selection correctly chooses **production / model-default temperature** among eligible full-dialogue configurations (127/138), narrowly ahead of examples/0.2 (125/138). Three repeats on one dialogue do not establish a meaningful general advantage from that two-check difference.

Keep the production prompt for now. Lower temperature is not a general improvement on this baseline. Do not adopt markup based on this pilot. For the next model comparison, use production/default as the main baseline and optionally examples/0.2 as a contrasting configuration: it improves this NPC address case but consistently misses the idiom. Improve the evaluation's coverage and review unseen dialogues before changing production.

No production prompt changes were made. The experiment used a smaller context than production's model-native default, so it does not measure the exact default production configuration.
